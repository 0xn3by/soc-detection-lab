# Synthetic fixture provenance

All four JSONL files are generated by [generate_events.py](../scripts/generate_events.py).
They contain fictional users, hosts, addresses, processes, and timestamps.
They are safe text, not executable scripts, malware samples, or real system logs.

- `brute-force.jsonl`: 12 Linux authentication-like events.
- `suspicious-powershell.jsonl`: 3 Windows process/script-like events.
- `admin-account-creation.jsonl`: 4 process/account/group-like events.
- `suspicious-network.jsonl`: 28 endpoint-enriched firewall-like events.

Total: 47 events, fixed on 2026-01-15 between 10:00:00 and 10:30:46 UTC.
Only `*.jsonl` is monitored, so this README is not ingested.

Run `python3 scripts/generate_events.py` from the root to reproduce byte-identical
fixtures. Existing identical files are left untouched. Generating one scenario
does not delete the other files. Use `--output-dir /tmp/soc-fixtures` to generate
an isolated copy; that path is not monitored by the default Splunk container.

Do not append real security logs, credentials, or personal information here.
See [field semantics and enrichment caveats](../docs/event-schema.md).
